Sobre o Caça ao Bug

Um jogo para aprender Python e lógica de programação. Um robô atravessa cenários e encontra bugs no caminho. Para seguir em frente, você corrige o código de cada bug.

Como jogar

  • Andar: setas ← → (ou os botões na tela, no celular).
  • Pular: ESPAÇO ou ↑ (ou o botão ⤒). Use para passar pelos blocos e pegar chips no alto.
  • Desafio: ao encontrar um bug, abre um código com uma lacuna. Escolha a peça certa e clique em VERIFICAR.
  • Se errar, você recebe uma dica sobre aquela peça e perde 1 chip.

Chips e meta

  • Colete chips pelo cenário. Responder um desafio rápido dá chips de bônus.
  • Para passar de mundo é preciso atingir a meta de chips mostrada no topo. Se faltar, o mundo recomeça.
  • Só dá para jogar um mundo depois de concluir o anterior.

Os mundos

  • Mundo 1: Floresta dos Loops (while, for, range, break).
  • Mundo 2: Caverna das Decisões (if, else e comparações).
  • Mundo 3: Laboratório de Funções (def, return e parâmetros).

Projeto acadêmico de computação, feito para ajudar quem está começando a programar.
